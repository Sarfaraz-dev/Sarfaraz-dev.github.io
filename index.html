Q1: Difference between Procedural and Object-Oriented Programming
What is the difference between Procedural Programming and Object-Oriented Programming? Explain with examples.
Procedural Programming:

Procedural programming is based on procedure calls. Programs are divided into functions or procedures that operate on data. Data and functions are separate.

  • Characteristics: Top-down approach, Global data, Functions manipulate data
  • Advantages: Easy to understand, Simple for small programs
  • Disadvantages: Difficult to maintain large programs, No data hiding
  • Example Languages: C, Pascal, FORTRAN
Object-Oriented Programming (OOP):

OOP treats data as objects that contain both data and functions. It follows bottom-up approach with concepts like encapsulation, inheritance, polymorphism.

  • Characteristics: Data hiding, Reusability, Modularity
  • Advantages: Easy maintenance, Code reusability, Better security
  • Disadvantages: Steeper learning curve, Overhead of objects
  • Example Languages: C++, Java, Python
Key Differences:
AspectProceduralOOP
ApproachTop-downBottom-up
Data AccessGlobalEncapsulated
ReusabilityLowHigh (Inheritance)
SecurityLowHigh (Data hiding)
MaintenanceDifficultEasy

Write a program to check if a given character is a vowel or consonant. 
// Vowel Check Program
#include <iostream>
#include <cctype>  // For toupper and isalpha
using namespace std;

int main() {
    char ch;
    
    cout << "Enter a character: ";
    cin >> ch;
    
    ch = toupper(ch);  // Convert to uppercase
    
    if(ch == 'A' || ch == 'E' || ch == 'I' || ch == 'O' || ch == 'U') {
        cout << ch << " is a vowel." << endl;
    } else if(isalpha(ch)) {
        cout << ch << " is a consonant." << endl;
    } else {
        cout << ch << " is not an alphabet." << endl;
    }
    
    return 0;
}
Output:
Enter a character: a A is a vowel.
Explanation:

The program takes a character input and uses conditional statements to check if it's one of the vowels (A, E, I, O, U). toupper() function handles both uppercase and lowercase inputs.

Time Complexity: O(1)

int reverseNum(int num) {

Q7: Check Armstrong Number
Write a program to check if a number is Armstrong number or not. 
// Armstrong Number Check
#include <iostream>
#include <math.h>
using namespace std;

int countDigits(int num) {
    int count = 0;
    while(num > 0) {
        count++;
        num /= 10;
    }
    return count;
}

int main() {
    int num, original, sum = 0, digits;
    
    cout << "Enter a number: ";
    cin >> num;
    original = num;
    digits = countDigits(num);
    
    while(num > 0) {
        int digit = num % 10;
        sum += pow(digit, digits);
        num /= 10;
    }
    
    if(sum == original) {
        cout << original << " is an Armstrong number." << endl;
    } else {
        cout << original << " is not an Armstrong number." << endl;
    }
    
    return 0;
}
Output:
Enter a number: 153 153 is an Armstrong number.
Explanation:

An Armstrong number is one where the sum of its digits raised to the power of number of digits equals the original number (e.g., 153 = 1³ + 5³ + 3³).

Time Complexity: O(log n)

// Fibonacci Series using Class
#include <iostream>
using namespace std;

class Fibonacci {
private:
    int n, first, second, next;

    // Constructor to initialize values
    Fibonacci() {
        first = 0;
        second = 1;
    }
    
    // Function to input number of terms

Fibonacci Series: " << endl;

Q11: Stack - Push and Pop Operations
What is Stack? Write Algorithm of Push and Pop operation.
What is Stack?

A Stack is a linear data structure that follows the LIFO (Last In First Out) principle. The element inserted last is the first one to be removed.

Basic Operations:

  • Push: Insert an element at the top of stack
  • Pop: Remove an element from the top of stack
  • Peek/Top: View the top element without removing it
  • isEmpty: Check if stack is empty
  • isFull: Check if stack is full

Applications: Function call management, Expression evaluation, Undo/Redo operations, Browser history

Algorithm for PUSH Operation:
Algorithm PUSH(STACK, TOP, MAX, ITEM):

Step 1: START
Step 2: IF TOP = MAX - 1 THEN
            PRINT "Stack Overflow"
            GOTO Step 6
        END IF
Step 3: TOP = TOP + 1
Step 4: STACK[TOP] = ITEM
Step 5: PRINT "Element inserted successfully"
Step 6: STOP
Algorithm for POP Operation:
Algorithm POP(STACK, TOP, ITEM):

Step 1: START
Step 2: IF TOP = -1 THEN
            PRINT "Stack Underflow"
            GOTO Step 6
        END IF
Step 3: ITEM = STACK[TOP]
Step 4: TOP = TOP - 1
Step 5: PRINT "Element deleted:", ITEM
Step 6: STOP
Implementation in C++:
// Stack Implementation
#include <iostream>
using namespace std;

#define MAX 5

class Stack {
private:
    int arr[MAX];
    int top;
    
public:
    Stack() {
        top = -1;
    }
    
    void push(int item) {
        if(top == MAX - 1) {
            cout << "Stack Overflow!" << endl;
            return;
        }
        top++;
        arr[top] = item;
        cout << item << " pushed to stack" << endl;
    }
    
    void pop() {
        if(top == -1) {
            cout << "Stack Underflow!" << endl;
            return;
        }
        cout << arr[top] << " popped from stack" << endl;
        top--;
    }
    
    void display() {
        if(top == -1) {
            cout << "Stack is empty" << endl;
            return;
        }
        cout << "Stack elements: ";
        for(int i = top; i >= 0; i--) {
            cout << arr[i] << " ";
        }
        cout << endl;
    }
};

int main() {
    Stack s;
    
    s.push(10);
    s.push(20);
    s.push(30);
    s.display();
    s.pop();
    s.display();
    
    return 0;
}
Q12: Queue - Insert and Delete Operations
What is Queue? Write an Algorithm of insert and delete Operation.
What is Queue?

A Queue is a linear data structure that follows the FIFO (First In First Out) principle. The element inserted first is the first one to be removed.

Basic Operations:

  • Enqueue (Insert): Add an element at the rear end
  • Dequeue (Delete): Remove an element from the front end
  • Front: Get the front element
  • Rear: Get the last element
  • isEmpty: Check if queue is empty
  • isFull: Check if queue is full

Applications: CPU scheduling, Disk scheduling, Print queue, Breadth-first search

Algorithm for INSERT (Enqueue) Operation:
Algorithm INSERT(QUEUE, FRONT, REAR, MAX, ITEM):

Step 1: START
Step 2: IF REAR = MAX - 1 THEN
            PRINT "Queue Overflow"
            GOTO Step 7
        END IF
Step 3: IF FRONT = -1 THEN
            FRONT = 0
        END IF
Step 4: REAR = REAR + 1
Step 5: QUEUE[REAR] = ITEM
Step 6: PRINT "Element inserted successfully"
Step 7: STOP
Algorithm for DELETE (Dequeue) Operation:
Algorithm DELETE(QUEUE, FRONT, REAR, ITEM):

Step 1: START
Step 2: IF FRONT = -1 OR FRONT > REAR THEN
            PRINT "Queue Underflow"
            GOTO Step 7
        END IF
Step 3: ITEM = QUEUE[FRONT]
Step 4: FRONT = FRONT + 1
Step 5: IF FRONT > REAR THEN
            FRONT = -1
            REAR = -1
        END IF
Step 6: PRINT "Element deleted:", ITEM
Step 7: STOP
Implementation in C++:
// Queue Implementation
#include <iostream>
using namespace std;

#define MAX 5

class Queue {
private:
    int arr[MAX];
    int front, rear;
    
public:
    Queue() {
        front = -1;
        rear = -1;
    }
    
    void insert(int item) {
        if(rear == MAX - 1) {
            cout << "Queue Overflow!" << endl;
            return;
        }
        if(front == -1)
            front = 0;
        rear++;
        arr[rear] = item;
        cout << item << " inserted to queue" << endl;
    }
    
    void remove() {
        if(front == -1 || front > rear) {
            cout << "Queue Underflow!" << endl;
            return;
        }
        cout << arr[front] << " deleted from queue" << endl;
        front++;
        if(front > rear) {
            front = -1;
            rear = -1;
        }
    }
    
    void display() {
        if(front == -1) {
            cout << "Queue is empty" << endl;
            return;
        }
        cout << "Queue elements: ";
        for(int i = front; i <= rear; i++) {
            cout << arr[i] << " ";
        }
        cout << endl;
    }
};

int main() {
    Queue q;
    
    q.insert(10);
    q.insert(20);
    q.insert(30);
    q.display();
    q.remove();
    q.display();
    
    return 0;
}
Q13: Bubble Sort Program and Algorithm
Write a Program along with an Algorithm of Bubble Sort.
What is Bubble Sort?

Bubble Sort is a simple sorting algorithm that repeatedly steps through the list, compares adjacent elements and swaps them if they are in wrong order. The pass through the list is repeated until the list is sorted.

Time Complexity: O(n²) - Worst and Average case
Space Complexity: O(1)

Algorithm for Bubble Sort:
Algorithm BUBBLE_SORT(ARRAY, N):

Step 1: START
Step 2: FOR i = 0 TO N-2
            FOR j = 0 TO N-i-2
                IF ARRAY[j] > ARRAY[j+1] THEN
                    SWAP ARRAY[j] and ARRAY[j+1]
                END IF
            END FOR
        END FOR
Step 3: PRINT "Sorted Array"
Step 4: STOP

Working:
- In each pass, largest element bubbles up to its correct position
- After first pass, largest element is at the end
- After second pass, second largest element is at second last position
- Process continues until array is sorted
Program:
// Bubble Sort Implementation
#include <iostream>
using namespace std;

void bubbleSort(int arr[], int n) {
    int temp;
    
    for(int i = 0; i < n-1; i++) {
        // Last i elements are already sorted
        bool swapped = false;
        for(int j = 0; j < n-i-1; j++) {
            // Swap if element is greater than next
            if(arr[j] > arr[j+1]) {
                temp = arr[j];
                arr[j] = arr[j+1];
                arr[j+1] = temp;
                swapped = true;
            }
        }
        // If no swapping, array is sorted
        if(!swapped) break;
    }
}

int main() {
    int arr[] = {64, 34, 25, 12, 22};
    int n = sizeof(arr)/sizeof(arr[0]);
    
    cout << "Original array: ";
    for(int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
    
    bubbleSort(arr, n);
    
    cout << "Sorted array: ";
    for(int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
    
    return 0;
}
Output:
Original array: 64 34 25 12 22 Sorted array: 12 22 25 34 64
Q14: Binary Search Program
Write a program for Binary Search on sorted array. 
// Binary Search Implementation
#include <iostream>
using namespace std;

int binarySearch(int arr[], int n, int key) {
    int low = 0, high = n - 1;
    int mid;
    
    while(low <= high) {
        mid = (low + high) / 2;
        
        if(arr[mid] == key) {
            return mid;
        } else if(arr[mid] < key) {
            low = mid + 1;
        } else {
            high = mid - 1;
        }
    }
    return -1;
}

int main() {
    int arr[10], n = 10, key;
    
    cout << "Enter 10 sorted numbers:" << endl;
    for(int i = 0; i < n; i++) {
        cout << "Element [" << i << "]: ";
        cin >> arr[i];
    }
    
    cout << "
Enter number to search: ";
    cin >> key;
    
    int result = binarySearch(arr, n, key);
    
    if(result != -1) {
        cout << "Element found at index: " << result << endl;
    } else {
        cout << "Element not found in array" << endl;
    }
    
    return 0;
}
Output:
Enter 10 sorted numbers: Element [0]: 10 Element [1]: 20 Element [2]: 30 Element [3]: 40 Element [4]: 50 Element [5]: 60 Element [6]: 70 Element [7]: 80 Element [8]: 90 Element [9]: 100 Enter number to search: 60 Element found at index: 5
Explanation:

Binary search works on sorted arrays by repeatedly dividing the search interval in half. It finds the target by comparing with the middle element.

Time Complexity: O(log n)

Prerequisite: Array must be sorted

Q15: Postfix Expression Evaluation
Write a program to evaluate postfix expression using stack. 
// Postfix Expression Evaluation
#include <iostream>
#include <stack>
#include <cctype>  // For isdigit
using namespace std;

int evaluatePostfix(string exp) {
    stack<int> st;
    
    for(int i = 0; i < exp.length(); i++) {
        char ch = exp[i];
        
        // If operand, push to stack
        if(isdigit(ch)) {
            st.push(ch - '0');
        }
        // If operator, pop two operands and apply
        else {
            int val2 = st.top(); st.pop();
            int val1 = st.top(); st.pop();
            
            switch(ch) {
                case '+': st.push(val1 + val2); break;
                case '-': st.push(val1 - val2); break;
                case '*': st.push(val1 * val2); break;
                case '/': st.push(val1 / val2); break;
            }
        }
    }
    return st.top();
}

int main() {
    string exp;
    cout << "Enter postfix expression: ";
    cin >> exp;
    
    cout << "Result: " << evaluatePostfix(exp) << endl;
    
    return 0;
}
Output:
Enter postfix expression: 23+5* Result: 25
Explanation:

Postfix (Reverse Polish Notation) evaluates expressions without parentheses. Stack is used: operands pushed, operators pop two operands, apply operation, push result.

Example: "23+5*" = (2+3)*5 = 25

Time Complexity: O(n) where n is length of expression

4. Constraints and Keys
  • PRIMARY KEY: Unique identifier for each record
  • FOREIGN KEY: Links two tables
  • NOT NULL: Field cannot be empty
  • UNIQUE: Ensures all values are different
  • CHECK: Specifies a condition
  • DEFAULT: Sets default value
5. Indexes

CREATE INDEX idx_student_name ON Students(Name);

SQL commands manage databases: DDL for structure, DML for data manipulation, DQL for querying. Indexes improve search performance but slow down inserts/updates.
